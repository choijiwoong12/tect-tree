# Tech Tree — 화면/플로우 문서 (디자이너 개편본)

Figma 전면 개편본 기준. 프레임명 = 페이지 설명. 동작 설명은 프레임 내 **초록 주석**으로 표기됨(= 스펙, UI 아님).
프레임 PNG: `../frames/<폴더>/<프레임명>.png`

- 마이페이지·토스 결제 UI 프레임은 제외(별도 페이지 아님 — 아래 참고).
- 공통 헤더: 좌상단 `ATHENA DOCTRINE` 로고 + 우상단 RP 카운터.

## 핵심 변화 (이전 설계 대비)
- **마이페이지 완전 삭제** → 메인 **좌하단 "자기 정보" 패널** + 모달들로 대체. (기존 코드 라우트 `/mypage`·`/mypage/profile`·`/mypage/rp`·`/mypage/payments`는 **제거 대상**.)
- **SHOP(RP 충전) 신설**(이전 미정) — RP 패키지 + 월 구독.
- **노드 열람 2-방식**: RP로 열람 / 구독권으로 열람.
- **콜사인이 회원가입에 통합·필수**: 4단계(알파벳→직업군→수준→성취도) 선택 완료 시 **즉시 적용·완료**(최종확인/나중에 하기/에러 없음).
- 노드 hover→2배+목차 미리보기, 열람 노드 목차에 읽음 표시(원 채움), 열람 노드 간 엣지 2배 굵기, 줌아웃 시 LEVEL 동심원.

#### 좌하단 패널 — 기본=사업자 정보 / 중심 노드 클릭 시 유저 정보 (같은 자리 토글)

## 2. 플로우 맵

```
[홈 로딩]  (올리브가지를 아테나로 드래그 → 진입)
   ▼
[로그인 전 트리]  중심 = LOG IN 버튼
   │ LOG IN 클릭 → Google OAuth
   ├ 최초 1회 → [회원가입: 이름/성별/나이/연락처+약관]
   │              → [CALL SIGN: 알파벳→직업군→수준→성취도]  (선택 완료 시 즉시 적용·완료)
   │              → 메인(로그인 후)
   └ 기존 회원 → 메인 직행
[로그인 후 트리]  중심 = 콜사인(START HERE)
   ├ 노드 hover → 2배 확대 + 목차 미리보기
   ├ 잠긴 노드 클릭 → [노드열람 모달]
   │     ├ RP로 열람 / 구독권으로 열람 → [노드 본문 뷰어]
   │     └ RP 부족·무구독 → [SHOP] 자동 이동
   ├ 열람된 노드 클릭 → [노드 본문 뷰어] (다크/화이트, 우측 목차)
   ├ 중심 콜사인 클릭 → 좌하단을 유저정보로 토글 (기본=사업자정보)
   ├ 자기정보 패널 ─ 콜사인→수정 / LAST NODE→직전노드 이동
   │                ├ (CUSTOMER SERVICE) → [고객센터 모달]
   │                ├ (NOTICE) → [공지] (화면 프레임 미제공)
   │                └ 구독 상태 클릭 → OFF: [SHOP-3 구독 안내] / ON: [정기구독 관리 모달]
   ├ 우상단 RP 카운터 클릭 → [SHOP] → 상품 선택(>)
   │     ├ RP 패키지 → Toss 결제
   │     └ 월 구독 → 이용안내 → 결제수단 등록(Toss)
   ├ 로고 클릭 → 중심 위치 복귀
   └ 계속 줌아웃 → (임계점에서) LEVEL 동심원 오버뷰로 전환 (별도 화면 아님)
```

## 3. 검증 결과 (2026-06-22 확정)

1. ✅ **콜사인**: 가입 필수. 4단계 선택 완료 시 **즉시 적용·완료**(최종확인/나중에 하기/에러 없음).
2. ✅ **NOTICE**: 자기정보 패널 기본정보 밑 `NOTICE` 클릭 시 공지 표시. (공지 화면 프레임은 미제공 — 필요 시 별도 요청)
3. ✅ **정기구독 상태 클릭**: 구독 OFF → SHOP-3(구독 결제 전 안내), 구독 ON → 정기구독 관리 모달.
4. ✅ 노드 뷰어 헤더 **로고 클릭 → 메인(트리) 복귀**.
